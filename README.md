# NaijaSpots — Discovery App for Nigerian Hangouts & Landmarks

NaijaSpots is a responsive, mobile-first Web application built with Next.js 14, Tailwind CSS, Framer Motion, and Supabase.

## Features
- Centered swipe deck with Framer Motion spring physics
- 15+ curated Nigerian spots across Lagos, Abuja, Oyo, Ogun, Rivers
- Dual storage: Supabase + localStorage optimistic sync
- Direct Google Maps routing for each spot
- Full saved spots hub at /saved
